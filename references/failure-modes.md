# 已知失败模式与处置

本文件记录翻译流程在真实文献上的已知失败模式与应对，评分项"异常处理"与
"可靠体验"要求如实识别并处置，而非假装成功。

| 场景 | 识别信号 | 处置 | 输出 |
|-|-|-|-|
| 加密/损坏 PDF | `pdftotext` 报权限或解析错误、页数为 0 | 不绕过权限；记录原始报错 | `status=failed` + `reason` |
| 无文字层扫描件 | 页面 0 词（`page_classes.empty`） | 有 `pdftoppm`+`tesseract` 时 300dpi OCR，TSV 真实坐标换算为 pt，标 `verified:false`；无 OCR 工具时该页不产出文字 | `unreadable`/`partial` + `uncertainties` |
| 少文本页（图表页） | 1~19 词 | 保留不误判为不可读；图题/表题若可读则翻译题注，图内文字不臆译 | 正常段落 + 题注翻译 |
| 公式为图片/上下标失真 | 公式符号被栅格化、`pdftotext` 输出残缺 | 按"结构元素"保留原符号串与编号，不猜测上下标；标 `uncertain` | `equation` 段 + `uncertain` |
| 表格为图片 | 无文字层表格、`markdown` 为空 | 题注可读则译题注；表格体标"图片型表格，未解析" | `table` 段 `note` 说明 |
| 参考文献无法解析 | 条目切分失败、编号错乱 | 逐条保留原始行，标"未解析"，不硬凑编号 | `reference` 段 + `uncertain` |
| 跨页/跨栏段落断行 | 段落 `cross_page=true` 或阅读顺序错乱 | 按段号续译，携带上一段结尾上下文，避免漏掉续接句/重复译 | 段号一一对应 |
| 原文残缺/扫描模糊 | 文字层缺词、OCR 低置信 | 残缺处标 `⚠️[原文残缺]`，不靠猜补齐 | `uncertain` + 译文标注 |
| 语言混杂（中英夹排） | 段落同时含中英文 | 按可读部分翻译，保留专名/术语原文，说明取舍 | `note` + `uncertain` |
| 术语多义/缩写歧义 | 同一词多义、缩写无定义 | 术语表 `note` 记录取舍依据，首次出现括注原文，列入 `uncertain` 供人工确认 | `terms.tsv` + `human_review` |
| `output_contract` 字段无法产出 | 材料缺失对应结构 | 置 `null` 并在 `uncertainties` 说明原因，不填假值 | `uncertainties` |
| 子进程超时/异常退出 | 600s 超时、返回码非零、产物损坏 | 记录 stderr 尾部；`case_id` 不符拒绝采用 | `status=failed` |

## 与基础 Agent 的差异点（本 Skill 新增能力）

1. 术语表以文件形式落盘并由核验脚本逐段 grep 强制，而非写在提示里听任模型自由发挥。
2. 分段由解析器按版面几何恢复阅读顺序并分配稳定段号，跨栏跨页不串行、不丢段。
3. 数字/单位/公式编号/文献引用在翻译前被确定性抽取、翻译后被确定性回查，缺失即报。
4. 否定/限定关系给出软检查清单，供人工确认而非含混通过。
5. 段落级双语对齐输出，每段可回指页码/bbox 并带译法依据与待确认标注。
