# 翻译方法与阈值

本 Skill 把"术语稳 / 段落全 / 关系准 / 可核验"四项要求拆成**确定性可执行**的步骤。
翻译本体由 Agent 完成；分段、保护令牌抽取与核验由脚本完成，保证可重复、可对照。

## 1. 分段与阅读顺序（段落全）

- `parse_pdf.py` 用 `pdftotext -bbox-layout` 取 block/line/word 三级包围盒，按块左边缘
  聚类识别 1~4 栏，通栏块（标题/跨栏图表/宽公式）作横带切分，带内栏从左到右，
  恢复跨栏、跨页阅读顺序；页眉页脚按跨页重复模式剔除。
- `segment.py` 重新运行解析器的块排序函数，把结构化元素（标题/作者/摘要/关键词/标题/
  正文段落/表题/图题/公式/参考文献）映射回全局阅读顺序，分配稳定段号 `T0001…`。
- 每段携带 `page`/`bbox`；跨页段落给多页 bbox。核验阶段要求段号一一对应、无缺译/多余。

## 2. 术语表抽取与锁定（术语稳）

- Agent 通读 `source.md` 抽取领域术语，写入 `terms.tsv`（`source→target→note`）。
- 锁定原则：一词一译；标题/摘要/正文/图注/表头/结论/参考文献标题同名术语统一。
  首次出现可括注原文；中途改译名须全篇回填并记录。
- 核验（`verify_translation.py`）用词边界匹配（`(?<![A-Za-z0-9])term(?![A-Za-z0-9])`，
  大小写不敏感）在原文命中术语，要求译文含锁定译名；`reference`/`equation` 段因保持
  原文而不参与术语检查。
- 术语一致率 = 一致命中数 / 总命中数，供与基础 Agent 对照。

## 3. 保护令牌抽取（关系准）

`segment.py` 对每段原文抽取以下"必须原样保留"的令牌：

| 类型 | 正则要点 |
|-|-|
| 数字 | `\b\d+(?:[.,]\d+)*(?:[eE][+-]?\d+)?\b`（整数/小数/科学计数） |
| 单位 | nm/mm/cm/km、eV/meV/keV/MeV/GeV/TeV、Hz/kHz/MHz/GHz、mol/mmol/μmol、mM/μM/nM/pM、mg/μg/kg、ms、kPa/MPa/GPa、mL/μL、%、‰、°C、°F |
| 文献引用 | `[3]`、`[3-5]`、`[3,7,9]`、`[Smith et al., 2020]` |
| 公式编号 | `(1)`、`(2.3)` |

核验时数字用 `(?<!\d)num(?!\d)` 判存在（句末句号/逗号是标点不是数字一部分，避免
"1"误命中"2019"、避免"2019."误判缺失）。

## 4. 否定/限定关系（关系准，软检查）

源文否定/限定词（no/not/without/never/only/all/none/rarely/cannot/lack/absence 等及
non-/un-/in-/im-/ir-/il-/dis-/mis- 前缀）计数；译文中文标记（不/未/无/非/没有/无法/仅/
所有/很少/缺乏/难以 等）计数。源文有否定而译文无中文标记者列入 `human_review` 清单
（软检查，不判硬失败——否定不是逐词对译）。

## 5. 核验输出与指标

`verify_translation.py` 输出：

- 完整性率 = 已译段数 / 总段数。
- 术语一致率 = 一致命中 / 总命中。
- 保护保留率 = 已保留令牌 / 应保留令牌。

三项指标均为可重复计算的实数，供平台做"加载 Skill vs 基础 Agent"的公平对照，
不依赖文字自述。

## 6. 可重复性与缓存

- `run_case.py` 以 `case/task/PDF` 的内容哈希为指纹；`--translation` 合并时指纹一致则
  直接复用阶段 1 产物，不重解析 PDF（`changes` 记录）。
- 阶段 1 运行前清理工作目录残留 `result.json`/`source.md`；子进程返回码/超时/损坏
  输出逐一检查；`case_id` 不符拒绝采用，杜绝跨案例串用。
